# Электронный дневник - Режим просмотра
## Описание
Программа для учащихся с ограниченным доступом. Предназначена только для просмотра оценок без возможности их изменения.

## Функционал
Просмотр оценок ученика - детальный просмотр успеваемости выбранного ученика

Оценки класса - обзор успеваемости всего класса

Список учеников - просмотр всех учащихся в базе данных

## Запуск
Запустите программу: python secondV.py

## Особенности
Только режим чтения (без изменения данных)

Удобный просмотр оценок по четвертям

Расчет средних баллов по предметам

Идеально для учащихся и родителей
