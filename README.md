# Электронный дневник - Режим преподавателя
## Описание
Программа для преподавателей с полным доступом к управлению электронным дневником. Позволяет добавлять учеников, выставлять оценки и проводить анализ успеваемости.

## Функционал
Добавление учеников - внесение новых учеников в базу данных

Выставление оценок - добавление оценок по предметам и четвертям

Просмотр всех оценок - полный обзор успеваемости всех учеников

Анализ двоек - подсчет количества двоек в выбранной четверти

Средние оценки - расчет средней успеваемости по классам

## Запуск
Запустите программу: python firstV.py

## Особенности
Полный контроль над данными дневника
